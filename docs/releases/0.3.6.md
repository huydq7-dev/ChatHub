# ChatHub 0.3.6 — Privacy Shield fixes

## What's fixed

- Consistent privacy masking across Telegram, Messenger and Zalo without stacking
  multiple blur layers on the same content.
- Hover reveals one row or message and covers it again when leaving, scrolling,
  switching accounts or deactivating ChatHub. Native toolbar focus no longer
  prevents hover previews.
- Zalo's large circular chat background is fixed. Avatars stay masked without
  clipping the entire conversation or rounding rectangular media.
- Messenger header names, stickers, attachments and reply previews are covered.
  Toolbar buttons and the composer remain usable.
- Privacy Shield works even when **Match macOS Appearance** is turned off.

## Installation

Download `ChatHub-macOS.dmg` or `ChatHub-macOS.zip` below. Quit ChatHub, then replace
`ChatHub.app` in Applications. Existing account metadata and local WebKit profiles
are preserved.

This release is locally signed. If macOS blocks the app, follow the installation
instructions in the README. Privacy adapters currently support Telegram, Messenger
and Zalo; they obscure the display and do not redact the provider's DOM or
accessibility tree.
